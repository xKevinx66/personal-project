# Personal Course Project Portfolio

This repository collects selected individual course projects completed while studying Data Science and Big Data Technology. It focuses on data processing, database design, object-oriented programming, and foundational algorithm implementation.

## Projects

| Project | Technology | Highlights |
| --- | --- | --- |
| [Property Investment Analysis](property-investment-analysis/) | Python, Pandas, NumPy, Matplotlib | CSV processing, descriptive statistics, currency conversion, visualisation, insertion sort, recursive binary search |

| [Vehicle Rental System](vehicle-rental-system-cpp/) | C++ | Abstract classes, inheritance, polymorphism, templates, STL containers, rental workflows, and text persistence |
